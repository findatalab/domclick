## Пропуски
Пропуски **не заполняются**: NaN остаётся в матрице, потому что `HistGradientBoostingRegressor`, XGBoost и LightGBM обрабатывают NaN сами, а заполнение до разбиения на фолды переносит информацию из теста в обучение. Рядом с каждым неполным полем добавлен индикатор пропуска (`*_missing`), чтобы линейные модели тоже могли использовать этот сигнал. Для линейных моделей заполните NaN медианой, посчитанной **только на обучающей части** каждого фолда.

## Как обучать на этой матрице
1. Целевая переменная: `log_asking_price_rub` для скошенного распределения (`skew` цены ≈ 9,8) — метрики затем пересчитывайте обратно через `expm1`.
2. Модели: `HistGradientBoostingRegressor` или LightGBM/XGBoost — они нативно работают с NaN; линейная регрессия потребует заполнения пропусков.
3. Разбиение: используйте `GroupKFold` с группами из `group_locality` — объявления одного населённого пункта (и, вероятно, одного физического дома) не должны попадать одновременно в обучение и тест.
4. Высококардинальные поля (`highway`, `locality`, `settlement`) даны one-hot для шоссе и частотным кодированием для населённых пунктов; target-encoding не используется, так как требует расчёта внутри фолда.
5. Признаки из текста описания (`txt_*`) — самая слабая по дисциплине часть набора: они извлекаются из рекламного текста, который может упоминать цену. Проверьте пересечение ключевых слов с ценой и при сомнениях отключите `--no-text-features`.

- Переход от 2 признаков к 103 поднимает R² на лог-шкале с 0,517 до 0,870, а MAE по сырой цене падает почти вдвое (57 → 31 млн ₽).

- Линейная модель на лог-цели при обратном преобразовании даёт RMSE в миллиарды рублей: `expm1` взрывается на экстраполяции. Ограничивайте прогноз обучающим диапазоном или обучайте на сырой цене.
- Важность признаков (permutation importance) распределена крайне неравномерно: `house_area_m2` даёт около 0,68 падения R², `distance_to_mkad_km` — 0,078, `house_area_per_floor` — 0,034, остальные меньше 0,03. Признаки из описания слабые (лучший `txt_*` — около 0,008), но не бесполезные.
