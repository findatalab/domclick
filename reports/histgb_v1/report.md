# HistGradientBoosting: модель цены предложения

Данные: `data\features\features_v1.csv`
Модель: `HistGradientBoostingRegressor` с early stopping (`max_iter=400`, `n_iter_no_change=20`, `validation_fraction=0.1`).
Признаков: **80**; строк: **1,144**; пропусков в матрице: **11,212**.
Цель: `log(asking_price_rub)`; метрики пересчитаны в рубли через `expm1`.
Валидация: GroupKFold по `group_locality` (5 фолдов, групп: 526, seed 42).
Подбор гиперпараметров: не выполнялся.

## Обработка пропусков
Пропуски **не заполняются**: `HistGradientBoostingRegressor` сам направляет объекты с NaN в отдельную ветвь. Это принципиально, потому что в матрице **11,212** пропущенных ячеек, и хотя бы один пропуск есть в **1,144** из **1,144** строк (100.0 %). Построчное удаление пропусков оставило бы **0** строк — HistGB сохраняет все данные.

## Ограничения
- `asking_price_rub` — цена предложения, а не подтверждённая цена сделки.
- Валидация групповая (`GroupKFold` по `group_locality`): объявления одного населённого пункта не попадают одновременно в обучение и тест, поэтому оценка консервативнее обычного `KFold`. Группировка не устраняет дубликаты одного физического объекта с разными `listing_id`.
- Целевая переменная скошена (skew ≈ 9,8): RMSE сильно зависит от нескольких дорогих объектов, поэтому рядом приведены MAE и медианная ошибка.
- Признак `badge_mortgage_discount_pct` — прокси продавца/сегмента (корреляция с ценой 0,82, немонотонен по цене). Проверяйте устойчивость результата без группы `badge_*`.
- Прогнозы обрезаются по диапазону обучающей части фолда (включено), поэтому модель не выдаёт цены за пределами наблюдённого диапазона.
- Модель не экстраполирует: для объектов вне обучающего распределения (другой регион, другой тип недвижимости) прогноз не обоснован.
